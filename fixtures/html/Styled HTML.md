# Styled HTML

The small, safe subset of inline HTML and CSS the editor draws. Every line
here is synthetic.

A <span style="color:red;">red word</span> in a sentence, and one whose
quotes Smart Typography curled: <span style=”color:red;”>still red</span>,
<span style=”color: navy; font-size: 1.5em”>navy and larger</span>.

<p style="text-align: center;">A centred paragraph.</p>

<center>A centre element.</center>

<div style="text-align: right">
Right-aligned text.
</div>

Inline: <b>bold</b>, <strong>strong</strong>, <i>italic</i>, <em>emphasis</em>,
<s>struck</s>, <del>deleted</del>, <u>underlined</u>, x<sup>2</sup>, H<sub>2</sub>O,
<mark>marked</mark>, <kbd>Ctrl</kbd> + <kbd>K</kbd> and
<a href="https://example.com">a link</a>.

Composed: <span style="color: #b5452c; background-color: #fff3c4"><b>bold on a
fill</b> and <i>italic</i></span>; <span style="font-size: 80%; font-style:
italic; text-decoration: underline">small underlined italics</span>.

Ignored: <span style="position: fixed; width: 9999px; color: rgb(0, 128, 0)">only
the colour applies</span>; <a href="javascript:alert(1)">not a link</a>;
<b>an unclosed tag leaves the rest of the note alone.
