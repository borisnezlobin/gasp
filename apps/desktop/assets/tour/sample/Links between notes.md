# Links between notes

Put a note's name in double square brackets to link to it, like [[Start here]]. Hold ⌘ and click a link to open it, or type `[[` and pick a note from the list that appears.

A link can point at a note that doesn't exist yet, like [[Ideas for later]]. Following it makes the note.

Put `!` in front of a link to show the other note right here:

![[Reading list]]

To see which notes link to the one you're reading, press ⌘P and run **Show backlinks**.
