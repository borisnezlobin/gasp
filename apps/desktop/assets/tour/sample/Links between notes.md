# Links between notes

Put a note's name in double square brackets to link to it, like [[Start here]]. To open a link, tap it on the iPhone while the keyboard is down, or hold ⌘ and click it on the Mac. Typing `[[` lists notes to link to.

A link can point at a note that doesn't exist yet, like [[Ideas for later]]. Following it makes the note.

Put `!` in front of a link to show the other note right here:

![[Reading list]]

To see which notes link to the one you're reading, run **Show backlinks** from the command palette.
