# Editor

A fast, native Markdown editor for an Obsidian vault. It's written in Rust, runs on macOS, Windows and Linux, syncs through GitHub, and every part of it can be changed through plain config files. An iPhone app is planned.

![A note on abstract algebra open in the editor, with inline math rendered in place, a highlighted phrase, and the word count for the current selection in the status bar](docs/screenshot.png)

[PLAN.md](PLAN.md) has the design and where each phase stands.
